# Race subsystem (SR.EXE: `0000:8d26`–`e569`, the physics half of the timer ISR `0000:238c`, the dashboard `0f38:0000`–`1640`, the race frame loop `0f38:7b22`)

Target: `work/SR_unp.exe` (DGROUP `3E96`), VGA path (`DS:8236 == -2`, `DS:0254 == 1`). Addresses as in
`port/RE_GUIDE.md`. Companion spec: **`port/spec/race_render.md`** (code segment `2645`: track generator,
road/scenery/opponent renderer, road advance `2645:1efc`, lateral road step `2645:213d`, collision test
`2645:206b`). Symbols: `port/spec/race_symbols.csv` (both files).

Confidence tags: **verified** (read instruction by instruction in `x86dis.py` / the emulator-aware
disassembly, see below), **likely**, **guess**.

**Floating point.** The C compiler emitted 8087-emulator calls: `INT 34h`–`3Bh` = escape opcodes
`D8`–`DF` + modrm, `INT 3Ch` = segment override, `INT 3Dh` = `FWAIT`. Ghidra shows these as `swi(0x35)`
garbage (`0000:c407`, `c497`, `c613`, `cdaf`, `d992`, `dcbe`, `e218`, `0f38:05f2`). All FP code in this
spec was read from a disassembly with the fix-ups decoded (replace `CD 34+n` by `9B D8+n`). The FP helpers
are `1e16:2de9` = `_ftol` (truncate toward 0, pops ST0), `1e16:3310`/`3316` = `sin`/`cos` (radians),
`1e16:23ec` = long divide `_aFldiv`, `1e16:2488` = long multiply, `1e16:255e` = long shift right by CL.
The port must evaluate these expressions in **IEEE double** in the same order (the emulator works in
80-bit, the difference never reaches the `_ftol` results for these small values; note it as an open
question). Segment `2beb` is the MSC 8087 emulator itself (INT 21h vector set-up, `fnstenv` …): runtime,
not game code.

**Not race code.** `0000:79eb` (car info: "Max speed %3i mph", "%2i gallons"), `0000:7aa4`
(tyres/bumpers?), `0000:7fb1` (engine tuning with the speaker running), `0000:81ab` ("Pop the hood",
installs parts) are **garage** screens called from the game loop `0000:503f`; only their use of
`car_max_speed 0000:e218` and `car_is_runnable 0000:7ee6` matters here. `0000:b8a1` is the **gas
station**, `0000:b08c` the **jail** screen (debts) — both reached through the drive sequence, documented
here in §4.3/§4.14 because they share its state.

## 1. Overview

Street Rod's "driving" is one engine used for four things, selected by `DS:0284` (destination) and
`DS:8ACA` (race flag):

| Use | Entry | `DS:0284` | `DS:8ACA` | What happens |
|---|---|---|---|---|
| Cruise to Bob's Drive-In | `0000:8d26` from the game-loop button 2 ("Hit the street"), needs > 0.8 gal (`503f`) | 2 | 0 | "Cruising in town...": automatic drive (the car accelerates and shifts by itself) until a track flag says "arrived"; then `0000:ab8b` (Bob's) |
| Cruise to the gas station | game-loop button 0xF ("Wanna tank ?") when the tank holds < 14.0 gal and money ≠ 0 (`503f`) | 3 | 0 | then `0000:b8a1` gas station |
| Cruise back to the garage | `0000:ab8b` "Back to the garage", `b717` after the gas station | 1 | 0 | returns to the game loop |
| Drag race / road race | `0000:d031` from the challenge `0000:9d6d` | (2) | 1 | "Get ready !" / "Go !", player physics in the timer ISR, opponent AI, police, results `0000:c613` |

There is **no town map** in this code: "cruising in town" is the same road renderer with the town
scenery; the track is generated by `2645:0d48`/`0b91` (race_render.md).

## 3. Globals and data structures

### 3.1 The car-physics block (`phys`, 0xC2 bytes): player `DS:78E0`, opponent `DS:79E2`

Both blocks have the same layout (opponent = player + 0x102). `car_setup` fills +0x1A…+0xBB, `phys_reset`
the rest. Names below are used in the pseudocode as `p->name`; player globals are `DS:78E0 + off`.

| Off | Player | Name | Type | Meaning |
|---|---|---|---|---|
| +00 | 78E0 | speed | i16 | **mph** (speedometer 0…130, results use it directly) |
| +02 | 78E2 | steer_in | i16 | steering input, ±0x18 (0 when no steering key this step) |
| +04 | 78E4 | wheel | i16 | steering-wheel angle ±0x18, drawn by `wheel_draw`; decays by (|w|>>2)+1 per step |
| +0A | 78EA | blowout_seg | i16 | track segment where the tyres blow (0 = never) |
| +0C | 78EC | tire_slip | i16 | `DS:54B2[grade*5 + wear/2000]`, added to the lateral drift factor |
| +0E | 78EE | rpm | i16 | engine rpm, 0x5DC idle … 0x1644 (5700) limiter |
| +10/+12 | 78F0/78F2 | — | | copy of curve rec 0 (`+44/+46`) at reset |
| +14 | 78F4 | rpm_up | i16 | rpm gain per step with gas (from the curve band) |
| +16 | 78F6 | rpm_down | i16 | rpm loss per step without gas |
| +18 | 78F8 | gear | i16 | 0 = neutral, 1…ngears |
| +1A | 78FA | gear_dirty | i16 | 1 = redraw shifter knob / new curve band |
| +1C | 78FC | ngears | i16 | `DS:5560[trans grade]` = 3,3,4,4 |
| +1E | 78FE | redline | i16 | `DS:555A[engine grade]` = 4500/5000/5200 (AI shift point) |
| +20 | 7900 | automatic | i16 | 1 = automatic transmission (trans grade 0) |
| +22 | 7902 | auto_shift_rpm | i16 | automatic up-shift rpm = gear-4 rec1 rpm_hi (`DS:5524[e]`) |
| +24 | 7904 | auto_mode | i16 | automatic selector: 1 = N, 2 = D (copy of +20 at set-up) |
| +26/+28 | 7906/7908 | — | i16 | −1 (automatic) |
| +2A | 790A | — | i16 | never written by `car_setup`; copied to +40 by `phys_reset` (quirk) |
| +34 | 7914 | ratio[5] | i16 | rpm per mph per gear (gear 0…4) |
| +3E | 791E | grip | i16 | `ftol((0x82 − class) * 5.0 / 50.0 + DS:5568[tyre grade])` (unused by race code found; renderer?) |
| +40 | 7920 | cur_ratio | i16 | `ratio[gear]` |
| +42 | 7922 | band | i16 | current curve band 0…2 |
| +44 | 7924 | curve[5][3] | 8 bytes each | per gear 3 bands `{rpm_lo, rpm_hi, up, down}` (gear stride 0x18) |
| +BC | 799C | result | u16 | result flags, see below |
| +BE | 799E | steps_at_stop | i16 | copy of +C0 when `race_stop_inputs` ran |
| +C0 | 79A0 | steps | i16 | physics steps since the start (player block only; 6.0688 per second) |

Result flags (`799C` player, `7A9E` opponent): `01` finished / race over, `04` engine blown (set as
`05`), `08` tyres blown (from `DS:787C` at results time), `10` transmission blown (`11`), `20` crash
(`21`), `40` caught by the police (`41`), `80` jumped the start (`81`). `03` = opponent crashed into /
AI obstruction ended the race (`da25`).

### 3.3 In-memory game data used here (owned by the garage spec / `HOT_DATA`)

**Car record** (`DS:7EB0` → garage car list, word offsets unless noted): `+00` value ($), `+02` model,
`+04` byte colour, `+05` byte value class, `+06` transmission part*, `+08` engine part*, `+0A` manifold
part*, `+0C/+0E/+10` carburettor parts*, `+12` tyre part*, `+14/+15` bytes (roof/bumper state),
`+16…` bytes (body parts, 3 = ok), `+1F` byte engine state (>0 = installed / <0 = sick), `+20` i8 ignition
timing (−8…+4, "Retard/Advance"), `+22` fuel in 0.1 gal (≤ 0xAA = 17.0 gal), `+24` flags: bits 8–12
paint, `0x2000`/`0x4000`/`0x8000` customisations (chopped roof, front and rear bumper stripped; the model
table decides whether the model had them: `DS:8DF2`/`8DF6`/`8DF8` per model).

**Part record**: `+02` wear 0…10000 (0x26AC = 9900 = broken), `+04` part type → `DS:4808[type*8]`
= `{u8 grade, u8 fits (1 GM, 2 Ford, 4 Chrysler, 7 all), u8 category (0 engine, 1 transmission,
2 carburettor, 3 manifold, 4 tyres), u8 0, u16 name msg, u16 price}`. Grades used by the physics:

| Category | Grades |
|---|---|
| engine | 0 V-6, 1 small V-8 (283/292/285), 2 big V-8 (327/351/340) |
| transmission | 0 automatic, 1 3-speed, 2 4-speed, 3 racing 4-speed |
| carburettor | 0 2-barrel, 1 4-barrel, 2 racing 4-barrel |
| manifold | 0 2-bbl, 1 4-bbl, 2 3×2-bbl, 3 2×4-bbl, 4 racing; number of carburettors `DS:5126[g]` = 1,1,3,2,2 (slots `+0C…`) |
| tyres | 0 plain, 1 brand name, 2 racing slicks |

**Car model** (`DS:7D86 + m*10`, 25 models + 0x19 = police): `+02` byte class (`DS:7D88`), `+04` word
stock drivetrain: bits 0–3 fits mask (make = `(w&0xF)>>1`), 4–5 tyre grade, 6–7 transmission grade,
8–10 engine grade, 11–13 manifold grade, 14–15 carburettor grade; `+06` name msg id, `+08` picture id.

**Opponent record** (`DS:7FF8 + i*0x12`, i = 0…0x15, 0x15 = the King; loaded from `HOT_DATA`, first
0x18C bytes): `+00` i8 driver class (challenge table row), `+01` i8 skill (shift-point offset ×100 rpm),
`+02` i8 clumsiness (AI mistakes), `+04` word picture, `+06` word name msg id, `+08` word car model,
`+0A` i8 colour, `+0B` i8 status (−1 gone, 1 met), `+0C` i8 counted races against the player, `+0D` i8 his wins against the player,
`+0E` flags (1/2/4 customisations → car `+24` bits), `+0F` paint, `+10` car re-rolled once.

## 4. Pseudocode

All variables are `int16` unless noted; `abs()` is the 16-bit `cwd/xor/sub` idiom (abs(−32768) = −32768).
`msg(id)` = `0000:3ab8(id)` (bubble text at `DS:2C02+id`). Menu ids passed to `0f38:4a66` are UI-library
resources (see the video/UI spec).

### 4.1 Drive entry: `drive_to 0000:8d26`, `drive_run 0000:8e2d` (verified)

```c
void drive_to(void)                       /* DS:0284 = destination already set */
{
    fire = 0; joy_buttons = 0; mouse_left = 0; drive_abort = 0;          /* 4732 471C 05EE 47EE */
    if (drive_dest == 0) return;
    car->fuel = car->fuel < 3 ? 0 : car->fuel - 2;                        /* 0.2 gal per trip */
    video_clear_pages();                                                  /* (*DS:78BE)() */
    if (drive_abort) return;                                              /* never true here */
    ui_mouse_mode(-4);                                                    /* 0f38:2d7e(0xFFFC) */
    has_clock = (PART_GRADE(car->trans) == 0);                            /* automatic → clock */
    phys_reset(&player);                                                  /* cdaf(78E0) */
    race_state = 0; racing = 0;
    drive_run();
}

int drive_run(void)
{
    if (racing) video_clear_pages();
    lights_green = 0; DS_8228 = 0;
    set_car_colour_regs(car->colour /*byte +4*/);                         /* 0000:67cf: EGA palette 6/7 */
    if (racing) opp_palette_set(opp_rec->colour /*DS:827C*/);             /* 8d9c: palette 0Ch/03h */
    int r = race_run();                                                   /* 0f38:7b22 */
    sfx_stop_engine(0); siren(0);                                         /* 0f38:7741(0), 7728(0) */

```
`opp_palette_set(i)`: on EGA/VGA/Tandy, `i == −1` restores the saved `(DS:51AC, DS:51AD)`; otherwise it
saves the current `(DS:044C, DS:0443)` once and programs attribute registers 0Ch and 03h with
`DS:50C2[2i]`, `DS:50C3[2i]` (pairs `04/0C 03/0B 02/0A 05/0D 01/09 07/0F`, i.e. the opponent car's two
body colours are palette entries 3 and 12). **This is palette code** (via `0f38:1f4b`), contrary to
FORMATS.md; the port applies it to its EGA palette model.

### 4.2 Race frame loop `race_run 0f38:7b22` (verified, VGA path)

```c
int race_run(void)
{
    do {                                         /* runs once on VGA (DS:58EE = 1 only for EGA -2 … see note) */
        video_page_mode(3);                      /* 0f38:0dbd(3): pages 822A/822E = 02EA, cursor off */
        gfx_flush();                             /* 0f38:a054 */
        video_clear_pages();
        pic = load_pic(0x3F6 /*LIB2 #14 cockpit 320×190*/, 2);
        if (has_clock) {                         /* LIB2 #240 clock face over the tach */
            face = load_pic(0x4D8, 2);
            blit(face → pic at (0x78,0x7A), full size);     /* (*DS:78A2) = masked blit */
        }
        blit(pic rows 0…0x64 → road page DS:8188 at (0,0)); /* rect {w,0x65, sx 0,sy 0, dx 0,dy 0} */
        blit(same → DS:82B4);                               /* second road page (VGA only) */
        blit(pic rows 100…189 (0x5A lines) → dash page DS:7678 at (0,0));   /* A000:0000 */
        road_first_frame();                      /* 2645:2429 (race_render.md) */
        shifter_draw(player.automatic, player.ngears);      /* 0f38:12f7 */
        shifter_knob(DS:7678, &player);          /* 0f38:14f2 */
        wheel_shown = 100; wheel_load();         /* 0f38:0f53 */
        wheel_draw(0, wheel_shown, DS:7678);     /* 0f38:1130 */
        shown_rpm = player.rpm; shown_speed = player.speed;
        speedo_init(player.speed);               /* 01d2 */
        shown_speed = needle_update(player.speed, shown_speed, 0);
        if (!has_clock) { tach_init(player.rpm); shown_rpm = needle_update(player.rpm, shown_rpm, 1); }
        else clock_draw();
    } while (DS_58EE > 1);
    DS_58EE = 0;
    crtc_split(99);  DS_824A = 100;              /* 21a0:0014(99): VGA line compare → dashboard below */
    road_init();                                 /* 2645:2114 */
    video_show();                                /* (*DS:78C2)() */
    for (;;) {
        road_frame();                            /* 2645:213d: render, ≥9 ticks per frame (§7) */
        if (demo == 99) { demo = 0x62; demo_quit(); }
        int r = race_logic();                    /* 8ea8 */
        int w = player.wheel;                    /* sampled after race_logic */
        if (r) break;
        if (player.gear_dirty) shifter_knob(DS:7678, &player);
        if (abs(player.speed - shown_speed) > 1) shown_speed = needle_update(player.speed, shown_speed, 0);
        if (!has_clock && abs(player.rpm - shown_rpm) > 1) shown_rpm = needle_update(player.rpm, shown_rpm, 1);
        if (w != wheel_shown) { wheel_draw(w, wheel_shown, DS:7678); wheel_shown = w; }
    }
    gfx_flush();
    /* copy the last road frame into both pages, split off, restore text pages (VGA: 0x65/0x64 lines) */
    crtc_split(-1); DS_824A = 0;
    video_page_mode(1);
    return r;
}
```
Notes: `DS:58E4` (CGA double-buffer) is 0 on VGA; the CGA/Tandy branches are left out. The dashboard is a
separate video page shown below scan line 99 by the CRTC line-compare split (video spec); the road is
drawn into two alternating pages above it (race_render.md). Needle/wheel drawing goes directly to
`A000` (`DS:787A = 0xA000`, `DS:767C = 0`).

### 4.3 Per-frame logic `race_logic 0000:8ea8` (verified)

```c
uint race_logic(void)
{
    if (!racing) {                                   /* ---- cruising ---- */
        if (race_state == 0) {
            DS_05D6 = 0;
            if (!skip_fx) sfx_engine_start(1);       /* 0f38:7001(1) */
            race_isr_install();                      /* 1aad: INT 8 ← 238c (sound + physics) */
            input_flush();                           /* 0e24 */
            race_state = 1;
            status_text(-1, "Cruising in town...");
            if (player.auto_mode == 1) player.auto_mode = 2;       /* selector to D */
            cruise_gain = cruise_accel[0];           /* DS:51D8[0] = 0x2A */
            player.gear = 1; player.gear_dirty = 1;
            return 0;
        }
        if (race_state != 1) return race_state;
        if (!demo) {
            char k = key_read();                     /* 2db6 */
            if (k == 0x1B || k == 0x1F) drive_abort = 1;
            if (mouse_present) { mouse_buttons(); drive_abort |= mouse_left; }
            if (joy_present)   { joy_read();      drive_abort |= joy_buttons; }
        }
        if (demo == 99) { demo = 0x62; demo_quit(); }
        if (!(TRACK_A[seg+1] & 1) && !(TRACK_B[seg+1] & 1) && !drive_abort) {   /* 389b:33F2/3CB2 low byte */
            player.rpm += cruise_gain;
            if (player.rpm > 0x125C) player.rpm = 0x125C;
            if (player.gear) player.speed = player.rpm / cruise_ratio[player.gear];   /* DS:51E2 */
            if (player.rpm < 0x1195) return 0;
            if (player.gear < player.ngears) {       /* up-shift at 4501 rpm */
                player.gear++;
                cruise_gain = cruise_accel[player.gear];
                player.rpm = cruise_ratio[player.gear] * player.speed;
                player.gear_dirty = 1;
                return 0;
            }
            cruise_gain = 0;
            return 0;
        }
        DS_4736 = 0; fire = 0;
        race_isr_remove();                           /* 1b27 */
        return 1;                                    /* arrived (or aborted) */
    }
    /* ---- racing ---- */
    switch (race_state) {
    case 0:
        DS_05D6 = 0;
        if (!skip_fx) sfx_engine_start(1);
        race_isr_install(); input_flush();
        race_state = 1;
        status_text(-1, "Get ready !");
        green_tick = ticks + (rand(0x67) + 0x6E);    /* DS:05CC/05CE, 32-bit add */
        return player.result | opp.result;
    case 1:
        if (player.speed >= 1) {                     /* moved before green */
            race_isr_remove();
            player.result |= 0x81;                   /* "Ya jumped the light" */
            return 1;
        }
        if (ticks >= green_tick) {                   /* signed 32-bit compare */
            race_state = 2;
            status_text(-1, "Go !");
            lights_green = 1;
        }
        return player.result | opp.result;
    case 2:
        race_step();                                 /* da25 */
        if (player.result == 0 && opp.result == 0) {
            if (player.speed < 1) return 0;
            status_text(-1, "    ");
            race_state = 3;
            return 0;
        }
        return 1;
    case 3:
        if (player.result == 0 && opp.result == 0) { race_step(); return 0; }
        return 1;
    default:
        return race_state;
    }
}
```
`TRACK_A`/`TRACK_B` are the far word arrays `389b:33F0` and `389b:3CB0` (race_render.md); the index is
`seg+1` because the code reads `389b:33F2 + seg*2`. Cruise speed therefore follows the fixed table
(1st gear ×0xC8 … 4th ×0x38 rpm/mph; gain 0x2A rpm per frame in 1st — index 0 of the table — then 0x0C/8/4 in 2nd/3rd/4th; `cruise_accel[1]` = 0x1A is never used), independent of the car. The
green light comes 110…212 ticks (1.5–2.9 s) after "Get ready !".

### 4.4 Car set-up: `car_setup 0000:dcbe`, `car_max_speed 0000:e218`, `model_car_setup 0000:e0e2` (verified)

Grades `G(part) = (int8)DS:4808[part->type*8]`. Tables (all `int16` in DGROUP):

| DS | Index | Values |
|---|---|---|
| 5504 | `e*5 + gear` (engine torque per gear) | e0: 500 600 300 100 70 · e1: 600 700 350 120 90 · e2: 600 760 380 140 90 |
| 5522 | `e*2 + {0,1}` rpm band limits | e0: 2900 4500 · e1: 2900 5000 · e2: 2500 5200 |
| 552E | `carb*5 + manifold` intake bonus | c0: 0 0 100 0 0 · c1: 0 50 0 100 75 · c2: 0 0 0 50 100 |
| 554C | engine | 0 50 100 |
| 5552 | transmission | 0 33 66 100 |
| 555A | engine (redline) | 4500 5000 5200 |
| 5560 | transmission (gears) | 3 3 4 4 |
| 5568 | tyres (grip base) | 9 8 5 |
| 556E | model class (weight/drag) | 40 44 48 60 64 68 80 84 88 … |
| 54DC | `trans*5 + gear` gear spread % | t0: 0 25 50 100 0 · t1: 0 25 50 100 0 · t2: 0 25 50 75 100 · t3: 0 30 50 80 100 |
| 54B2 | `tyre*5 + wear/2000` tyre slip | t0: 2 5 8 11 14 · t1: 0 2 4 6 8 · t2: 0 0 1 2 4 |

Doubles (`DS:6980…`): 0.6, 0.09, 0.05, 0.01, 0.1, 88.0, 0.15, 100.0, 0.25, 8.0, 1.0, 0.2, 10000.0, 0.8,
0.3, 0.7, 130.0, 0.0, 5700.0, 5.0, 50.0 (`6980 6988 … 6A20`, 8 bytes apart).

```c
/* performance factor, shared by car_setup and car_max_speed (identical code) */
double perf(car_t *c, int e, int carb, int man, int tr, int model)
{
    double s = (double)((c->flags & 0x2000) || MODEL_8DF2[model] == 0) * 0.09     /* DS:6988 */
             + (double)((c->flags & 0x8000) || MODEL_8DF8[model] == 0) * 0.05     /* DS:6990 */
             + (double)((c->flags & 0x4000) || MODEL_8DF6[model] == 0) * 0.01     /* DS:6998 */
             + (double)W556E[CLASS(model)] * 0.1 / 88.0
             + (double)W552E[carb*5 + man] * 0.15 / 100.0
             + (double)W554C[e]            * 0.25 / 100.0
             + (double)W5552[tr]           * 0.15 / 100.0
             + (1.0 - fabs((double)c->timing / 8.0)) * 0.2;                        /* +20 i8 */
    s = (10000.0 - (double)c->engine->wear) / 10000.0 * s;
    return (tr == 0 ? 0.8 : 1.0) * s * 0.3 + 0.7;                                 /* f */
}
/* MODEL_8DF2[m] = *(int16*)(DS:8DF2 + m*10) etc. (model table extension, runtime data) */

int car_max_speed(int model)                  /* e218; model < 0 → the player's car */
{
    car_t tmp, *c = (model < 0) ? car : build_stock_car(model, &tmp);            /* see below */
    double f = perf(c, G(c->engine), G(c->carb[0]), G(c->manifold), G(c->trans), c->model);
    double v = f * 130.0;
    if (v > 130.0) v = 130.0;
    return _ftol(v);                          /* mph */
}

void car_setup(car_t *c, phys_t *p)           /* dcbe */
{
    int e = G(c->engine), carb = G(c->carb[0]) /*+0C*/, man = G(c->manifold) /*+0A*/;
    int tr = G(c->trans), ty = G(c->tyres);
    double f = perf(c, e, carb, man, tr, c->model);
    double g = f * 130.0; if (g > 130.0) g = 130.0;                               /* top speed */
    for (int gear = 0; gear <= 4; gear++) {
        double r = (double)W54DC[tr*5 + gear] * g / 100.0;
        if (r == 0.0) r = 0.2;
        p->ratio[gear] = _ftol(5700.0 / r);                  /* rpm per mph */
        crv_t *b = p->curve[gear];                           /* 3 bands */
        b[0].rpm_lo = 0;                 b[0].rpm_hi = W5522[e*2];
        b[1].rpm_lo = W5522[e*2];        b[1].rpm_hi = W5522[e*2+1];
        b[2].rpm_lo = W5522[e*2+1];      b[2].rpm_hi = 0x1644;
        int v = _ftol((double)W5504[e*5 + gear] * f);
        int m1 = (gear == 1 && ty != 2) ? 2 : 1;             /* launch in 1st: ×2, slicks ×3 */
        int m2 = (gear == 1 && ty == 2) ? 3 : 1;
        b[0].up = m2 * m1 * (v / (gear ? 5 : 1));           /* evaluation: m2*m1, then *(v/d) */
        b[1].up = v;
        b[2].up = v / (gear ? 10 : 1);
        for (int k = 0; k < 3; k++) b[k].down = gear ? v / (5 - gear) : v;
    }
    p->automatic = p->auto_mode = (tr < 1);
    if (p->automatic) {
        p->f28 = p->f26 = -1;
        p->auto_shift_rpm = p->curve[4][1].rpm_hi;           /* = W5522[e*2+1] */
    }
    p->redline = W555A[e];
    p->grip    = _ftol((double)(0x82 - CLASS(c->model)) * 5.0 / 50.0 + (double)W5568[ty]);
    p->ngears  = W5560[tr];
    p->gear_dirty = 1;
}
```
The customisation terms are 1 when the car has the modification bit (`+24`: 0x2000 roof chopped?,
0x8000/0x4000 bumpers stripped?) or when the model never had the part (`*(int16*)(DS:8DF2/8DF8/8DF6 +
model*10) == 0`, runtime model-table columns) — i.e. stripping weight/drag adds up to 0.15. Integer divisions are C `/` (truncate). `_ftol`
truncates toward zero.

whose parts are temporary part records `{wear, type}` with `wear = DS:496A` (= **−128**, so a stock

### 4.6 Controls (verified; the drivers are in the platform spec)

The physics step reads the input state that the keyboard ISR (`0000:2e93`), the joystick poll
(`0000:2df4`, port 201h, counts into `DS:4718/471A`) and the mouse poll (`0f38:7a47`, INT 33h fn 0Bh
motion scaled by `>> DS:05EA/05EC`, fn 03h buttons) leave in DGROUP:

| Control | Keyboard (scan code → `DS:4766` map) | Joystick | Mouse |
|---|---|---|---|
| steer left/right | ← / → (also Home/PgUp/End/PgDn diagonals, keypad) → `key_x` | x outside `[4722,4724]` → `steer_step ∓1` | horizontal motion → `steer_step += sign(dx)` |
| gas | ↑ (and diagonals up) → `key_y = −1` | y < `4726` | right button |
| brake | ↓ (keypad −, diagonals down) → `key_y = +1` | y > `4728` | moving the mouse down (`dy > 0`) |
| shift | Space / Ins (`fire` bit 0) | button (bit 1) | left button (bit 2) |
| abort cruise | Esc (0x1B) or key code 0x1F | button | left button |
| sound on/off | Ctrl (map code 0x1D toggles `DS:47CE`) | | |

The direction keys add their `(dx,dy)` pair from the table at `DS:4766−2n` on make and subtract it on
break, so opposite keys cancel. A **shift event** is the rising edge of `fire` (any source) or
`DS:47CD`. In a manual car every shift event changes gear by one: **down** if braking, or if the rpm is in
the lowest band and the gas is not pressed; otherwise **up** (see §4.7). Automatic cars toggle N↔D.
Mapping for the port: keep the XT scan-code path of the platform spec; the mouse/joystick paths are
optional host features.

### 4.7 Player physics — timer ISR `0000:238c`, part from `2513` (verified)

The ISR runs at every PIT tick (72.8 Hz, divisor 0x4000). Ticks with `tick_div4 != 0` only do sound
(sound spec). On every 4th tick it chains the BIOS handler (`ticks18++`) and then, **on every 3rd of those
(every 12th PIT tick = 6.0688 Hz)**, one physics step for the player's car, only while `racing` and not
`sound_alt`:

```c
void phys_step(void)                          /* 0000:253b … 2b8d; p = &player (DS:78E0) */
{
    if (--phys_div3 > 0) return;  phys_div3 = 3;
    cli(); if (phys_busy) return; phys_busy = 1; sti();
    bool steer = 0, gas = 0, brake = 0, shift;

    if (keys_idle == 0) {
        if (key_x) { steer = 1; steer_step = key_x > 0 ? 1 : -1; }
        if (key_y) { if (key_y > 0) brake = 1; else gas = 1; }
        if (!demo && joy_present) {
            joy_read();
            if      (joy_x < joy_x_lo) { steer = 1; DS_6C4A = 1; steer_step--; }
            else if (joy_x > joy_x_hi) { steer = 1; DS_6C4A = 1; steer_step++; }
            if      (joy_y < joy_y_lo) { gas   = 1; DS_6C4A = 1; pedal_step--; }
            else if (joy_y > joy_y_hi) { brake = 1; DS_6C4A = 1; pedal_step++; }
        }
        if (!demo && mouse_present) {
            mouse_poll();                                         /* 0f38:7a47 */
            if (mouse_dy > 0) { DS_6C4A = 1; pedal_step++; brake = 1; }
            if (mouse_dx)     { steer = 1; DS_6C4A = 1; steer_step += mouse_dx > 0 ? 1 : -1; }
            if (mouse_right)  gas = 1;
        }
    }
    shift = (fire && !fire_prev);  fire_prev = fire;
    if (shift_request) { shift = 1; shift_request = 0; }

    if (demo || auto_drive) {                                     /* the computer drives */
        if (p->rpm_up * 4 + p->rpm < 0x1644) {
            if (opp_seg > seg || seg > track_end_c() - 0x3C) gas = 1;   /* track_end_c: 0x17C/0x3FC */
        } else if (p->gear < p->ngears && DS_8228) { shift = 1; gas = 1; demo_shifts++; }
        if (p->rpm < 2000 && p->gear > 1 && !gas) shift = 1;
        if (p->automatic && p->gear > 0) shift = 0;
    }
    if (racing) { distance += p->speed; p->steps++; }             /* 32-bit add, sign-extended */
    if (seg > track_end_c()) {                                    /* past the finish: stop the car */
        brake = 1; steer = 0; gas = 0;
        if (p->speed > 0xF) p->speed -= 0xF;
    }
    if (ai_brake > 0) { brake = 1; steer = 0; gas = 0; ai_brake--; }   /* DS:54DA, spin-out */

    part_t *eng = car->engine, *trn = car->trans;
    if (p->rpm > 5000) { eng->wear++; trn->wear++; }
    if ((ticks18 & 0xF) == 0) eng->wear++;                        /* 32-bit test of DS:0600 */
    int w = eng->wear;
    if (w >= 0x26AC) { p->result |= 5; race_stop_inputs(); }     /* engine blown */

    if (gas) {
        p->rpm += p->rpm_up;
        if (p->automatic && p->rpm > 0x163A) p->rpm = 0x163A;
        if (p->rpm > 0x1644) {
            p->rpm = 0x1644;
            if (-(w / 1000 - 15) < ++limiter_count) { p->result |= 5; race_stop_inputs(); }
        }
    } else if (p->rpm > 0x5DC || (p->gear > 0 && p->rpm > p->rpm_down)) {
        p->rpm -= p->rpm_down;
    }
    if (p->rpm < 0x1644) limiter_count = 0;

    bool stall = (p->speed < 5 && !gas && p->gear > 0);
    if (shift || stall ||
        (p->automatic && p->auto_mode > 1 &&
         ((gas && p->rpm > p->auto_shift_rpm && p->gear < p->ngears) ||
          (!gas && p->gear > 1 && p->band == 0)))) {
        trn->wear += (p->rpm > 5000) ? 0xF : 3;
        if (!demo) {
            int tw = trn->wear;
            if (tw >= 0x26AC ||
                (!p->automatic && gas && p->rpm > 5000 && tw / 100 + 100 > rand(0xCCD))) {
                p->result |= 0x11; race_stop_inputs();            /* transmission dropped */
            }
        }
        if ((brake || (p->band == 0 && !gas)) && p->gear > 0) p->gear--;
        else if ((gas || (p->band > 0 && !brake)) && p->gear < p->ngears) p->gear++;
        if (p->automatic) {
            if (shift) p->auto_mode = (p->auto_mode == 1) ? 2 : 1;
            if (stall || p->gear == 0) p->auto_mode = 1;
            if (p->auto_mode == 1) p->gear = 0;
        } else if (stall) p->gear = 0;
        p->gear_dirty = 1;
        p->cur_ratio = p->ratio[p->gear];
        p->rpm = p->speed * p->cur_ratio;                         /* 16-bit imul, low word */
        if (p->rpm == 0) p->rpm = 0x5E1;
    }
    int k = 0;                                                    /* rpm band */
    while (k < 2 && p->curve[p->gear][k].rpm_hi < p->rpm) k++;
    if (k != p->band || p->gear_dirty) {
        p->band = k;
        p->rpm_up = p->curve[p->gear][k].up;
        p->rpm_down = p->curve[p->gear][k].down;
    }
    if (brake || (offroad && p->speed > 8)) {
        p->speed -= (p->speed >> 4) + 2;
        if (p->speed < 0) p->speed = 0;
        p->rpm = p->speed * p->cur_ratio;
        if (p->rpm < 0x5DC) p->rpm = 0x5DC;
    } else if (p->gear == 0 && p->speed != 0) {
        p->speed--;  p->rpm = p->speed * 0x1E + 0x5DC;            /* coasting in neutral */
    } else if (p->cur_ratio != 0) {
        p->speed = p->rpm / p->cur_ratio;                         /* idiv */
    }
    /* steering */
    if (steer && abs(p->steer_in + steer_step) > abs(p->steer_in)) {
        if (abs(steer_step) + abs(p->wheel) == abs(p->wheel + steer_step) &&
            abs(p->steer_in) < abs(p->wheel))
            p->steer_in = p->wheel;
        p->steer_in += steer_step * 2;
        if (abs(p->steer_in) > 0x18) p->steer_in = p->steer_in > 0 ? 0x18 : -0x18;
        steer_step = 0;
        p->wheel = p->steer_in;
    } else p->steer_in = 0;
    if (abs(p->wheel) > 0)
        p->wheel += p->wheel > 0 ? -((p->wheel >> 2) + 1) : ((-p->wheel) >> 2) + 1;
    if (racing && road_collide())                                  /* 2645:206b */
        { p->result |= 0x21; race_stop_inputs(); }                 /* crash */
    phys_busy = 0;
}
void race_stop_inputs(void)                                        /* 0000:2374 */
{ DS_05D6 = 0; p->wheel = p->steer_in = 0; p->rpm_down = p->rpm_up = 0; p->steps_at_stop = p->steps; }
```

**The model in words.** Speed is not integrated from a force: the engine rpm rises by `rpm_up` per
step while the gas is held (falls by `rpm_down` otherwise) and the speed is `rpm / ratio[gear]`. The
curve bands give a weak low-rpm band (`v/5` except in 1st gear, where it is `2v/5`, `3v/5` with slicks,
and in neutral `v`), the full `v` between the band limits (2900–4500/5000, 2500–5200) and `v/10` above,
where `v = torque[engine][gear] * f`. Shifting recomputes the rpm from the speed (`speed * ratio`), so a
too-early up-shift drops into the weak band. Braking removes `speed/16 + 2` mph per step; driving on the
shoulder brakes too above 8 mph. `f` (0.7…1.0 + small bonuses) and the top speed `min(130, 130f)` come
from the parts, the tuning, the engine wear and the customisations. Fuel is not consumed during the race
(only per trip: 0.2 gal per cruise leg, 0.5 gal after a drag race, 1.5 gal after a road race, §4.13).

Worked example (verified arithmetic): stock V-8 327 engine (e = 2), 4-speed (tr = 2), 4-barrel carb on
a 4-barrel manifold (bonus 50), plain tyres, class 0, no customisation, timing 0, engine wear 0:
`s = 0 + 0 + 0 + 40·0.1/88 + 50·0.15/100 + 100·0.25/100 + 66·0.15/100 + 1·0.2 = 0.0455+0.075+0.25+0.099+0.2
= 0.6695`; `f = 1.0·0.6695·0.3 + 0.7 = 0.90085`; top speed `_ftol(117.1) = 117 mph`;
ratios `5700/(p·117.11/100)` = 28500 for gear 0 (`r = 0 → 0.2`), 194 (25 %), 97 (50 %),
64 (75 %), 48 (100 %).

```c
void player_advance(void)                                     /* d624 */
{
    seg_step = player.speed ? speed_to_step(player.speed) : 0;
    seg_frac += seg_step;
    if (seg_frac > 7) road_advance();                         /* 2645:1efc: seg += frac>>3, frac &= 7 */

int speed_to_step(int v)                                      /* d544: eighths of a segment per frame */
{
    if (v < 1) return 0;
    if (cpu_class < 4) return v < 0x48 ? (v >> 3) + 1 : (v >> 2) - 8;
    static const struct { int lt, r; } T[] = { {0x0E,1},{0x1C,2},{0x2A,3},{0x38,4},{0x46,5},{0x54,6},
        {0x62,7},{0x66,8},{0x6A,9},{0x6E,10},{0x72,11},{0x76,12},{0x7A,13},{0x7E,14},{0x82,15} };
    for (i = 0; i < 15; i++) if (v < T[i].lt) return T[i].r;

}

{

    race_time = (float)((double)player.steps / 6.068827333333334);
```

The race is decided at the moment the first car reaches `track_end` (`player_ahead`), but the flags are
set only when the player has also **stopped** (`speed < 1`) past the line — the car keeps rolling and
the ISR brakes it 15 mph per step past `track_end_c()` (§4.7). `pct_covered` is only meaningful when the
opponent finished first (it divides by the opponent's distance; a zero divisor is possible if the
opponent never left the line — open question, the emulator returns ±inf and `_ftol` gives 0x8000).

### 4.10 Opponent speed `opp_ai 0000:d29d` and gear choice `opp_gear 0000:d1de` (verified)

The opponent runs its own simplified engine, **once per player physics step** (it catches up on all
steps elapsed since the last frame), with a "rubber band" to the player's speed:

```c
void opp_ai(void)
{
    int v0 = opp.speed, lim = 0 /* keeps its value between iterations (uninitialised local) */;
    int n = player.steps - ai_steps_done;  ai_steps_done = player.steps;
    for (int i = 0; i < n; i++) {
        if (CURVE[opp_seg+1] == CURVE[opp_seg]) {             /* 389b:4570: no curve here */
            DS_54D6 = 0;
            int d = opp_seg - seg;
            if (d < 0xD || (race_type == 1 && vs_king)) {
                if (d > -5 && d < 5) {                        /* alongside: stay near the player */
                    lim = player.speed + opp_slack;
                    if (seg > 0x1D && lim < opp_v70) lim = opp_v70;
                    if (lim < opp.speed) { opp_gear(lim, &opp); continue; }
                }
            } else {                                          /* ≥ 13 segments ahead: ease off */
                lim = opp_v80;
                if (player.speed < 0x61 && !vs_king) lim = opp_v70;
                if (lim < opp.speed) { opp_gear(lim, &opp); continue; }
            }
            if (police_state >= 2 && player.speed >= 0x33 &&
                opp.speed > (lim = player.speed + 0x20)) { opp_gear(lim, &opp); continue; }
            /* accelerate */
            opp.rpm += opp.band_up;
            if (opp_shift_rpm < opp.rpm) opp.rpm = opp_shift_rpm;
            if (opp.band_hi < opp.rpm) {
                opp.band++;
                crv = &opp.curve[opp.gear][opp.band];
                opp.band_hi = crv->rpm_hi; opp.band_up = crv->up;
            }
            if (opp.gear < opp.ngears &&
                ((opp.automatic && opp.auto_shift_rpm <= opp.rpm) || opp_shift_rpm <= opp.rpm)) {
                opp.gear++;
                if (!opp.automatic) {
                    if (opp.gear < opp.ngears) opp_shift_rpm = opp.redline - opp_skill * 100;
                    else if (cpu_class < 4 && video_driver != -6) opp_shift_rpm = 0x14B4;
                    else opp_shift_rpm = 0x1518;
                }
                opp.cur_ratio = opp.ratio[opp.gear];
                opp.rpm = opp.speed * opp.cur_ratio;
                crv = &opp.curve[opp.gear][1]; opp.band = 1;
                if (opp.rpm >= crv->rpm_hi)       { opp.band = 2; crv = &opp.curve[opp.gear][2]; }
                else if (opp.rpm < crv->rpm_lo)   { opp.band = 0; crv = &opp.curve[opp.gear][0]; }
                opp.band_hi = crv->rpm_hi; opp.band_up = crv->up;
            }
            opp.speed = opp.rpm / opp.cur_ratio;
        } else if (DS_54D6 == 0) {                             /* entering a curve: brake once */
            DS_54D6 = 1;
            lim = opp_vmax - (seg < opp_seg ? opp_rec->clumsy : opp_rec->clumsy >> 1);
            if (lim < opp.speed) opp_gear(lim, &opp);
        }
    }
    if (opp_seg >= track_end) {                               /* past the line: slow down */
        int dec = (seg + 5 < opp_seg) ? 5 : 10;
        opp.speed = (dec < v0) ? v0 - dec : 0;
    }
}
```

## 7. Timing

| What | Rate | Code |
|---|---|---|
| tick counter `DS:05F8` | every PIT tick, **72.8 Hz** | both INT 8 handlers |
| sound (engine pitch, siren, squeal) | 3 of every 4 ticks | `238c` (sound spec) |
| BIOS chain, `ticks18` | every 4th tick, 18.2 Hz | `238c` |
| **player physics step** | every 12th tick, **6.0688 Hz** (`1193182/65536·4/12`); constant `DS:6954` = 6.068827333333334 converts steps to seconds | `238c:253b` (racing only) |
| opponent engine (`opp_ai`) | once per player physics step, executed in a burst inside the next frame | `d29d` |
| **frame** (render + `race_logic` + dashboard) | the renderer busy-waits until **9 ticks** after the frame's start → ≤ **8.09 fps** (123.6 ms) | `2645:1e9e` |
| track position (player and opponent) | per **frame**: `speed_to_step(speed)` eighths of a segment | `d624`, `d67d` |
| cruise acceleration / up-shifts | per frame | `8ea8` |
| start light | 110…212 ticks after "Get ready !" | `8ea8` |
| menus at Bob's | opponent arrivals after 0x8C / 0x118 ticks | `ab8b` |

**CPU-speed dependencies.**
1. The frame is a *minimum* of 9 ticks. On a machine too slow to render a frame in 123.6 ms the frames get
   longer; since track advance is per frame while speed is per physics step, a slower machine covers
   *less* track per second (the race is effectively slow motion, but the race time — counted in physics
   steps — keeps running). On any machine that renders in < 9 ticks the game is deterministic in frames.
2. `DS:8ACC` (CPU class from the start-up loop count, `0000:05c6`): `< 4` switches `speed_to_step` to the
   coarse formula, `opp_slack` 10 instead of 16, the opponent's top-gear shift point (0x14B4 vs 0x1518),
   the lane logic (`d ≤ 4` vs `d ≤ 2`), the track generator (`DS:82C6`, race_render.md) and the
   renderer's opponent poses (`2645:3f8d` only animates poses when `8ACC > 3`).
3. The engine-sound pitch uses `shr ax, cl` with CL = low byte of a value + 2: on 8088/8086 the count is
   not masked (shift ≥ 16 → 0), on 186+ it is masked to 5 bits (sound spec).

**Port proposal.** Drive everything from the 72.8 Hz host tick exactly like the original: the host
tick handler increments `ticks`, runs the sound dividers and, every 12th tick while racing, `phys_step()`
(run it synchronously on the game thread between frames at the tick where it falls, not preemptively —
the original can interrupt a frame at any instruction, but the only shared state that matters is read
once per frame). The frame loop renders, then waits (calling `host_pump()`) until `ticks ≥ start + 9`.
That fixes the race at **8.09 fps with 6.07 physics steps per second**, the behaviour of a fast
(386-class) PC, which is what the timings were tuned for. Set `cpu_class` to a "fast" value
(recommend **`DS:8ACC = 20`**, any value ≥ 4 gives identical game logic; make it a config option so the
XT behaviour (1…3) can be reproduced). Do **not** raise the frame rate: track advance is per frame,
so 2× the frames would double the car's speed along the track (an Enhanced version would have to scale
`speed_to_step` and the per-frame cruise gains). The interleaving is fixed: with start phase φ, physics
steps happen at ticks ≡ φ (mod 12) and frames every 9 ticks, i.e. 4 steps per 3 frames.

## 8. Open questions

1. `DS:47CD` (forced shift event) is read and cleared but never set in SR.EXE — dead code or set through a
   pointer (check `0f38` UI code for writes via `DS:47CC` + 1).
2. `phys_reset` copies `+2A` (never written by `car_setup`) into `cur_ratio`; harmless because the first
   shift or the neutral path overwrites it, but the first `rpm/cur_ratio` of an opponent block relies on
   `opponent_setup` fixing it. Confirm `+2A` is not written elsewhere (renderer?).
3. `DS:8228` (enables the demo up-shift) and `DS:8BC2`/`DS:72F2`/`DS:7D7C` are written by the renderer
   `2645:3dc3`/`3f8d`; their exact meaning is in race_render.md.
4. `pct_covered` divides by `opp_seg − 200`; if the opponent never moved (e.g. the player finished before
   the opponent crossed the start segment — impossible in practice) the emulator's ±∞ → `_ftol` result
   0x8000 would be clamped? (it is > 99 test on a negative → not clamped). Reproduce by using the
   same integer conversion as the port's `_ftol` (saturate to 0x8000).
5. The 8087 emulator computes in 80-bit extended precision; C `double` may differ in the last bit of
   `perf()`. `_ftol` of `f*130` or of `torque*f` could flip at exact integer boundaries (none found for
   the stock tables; wear values could hit one). Use `long double` if the host supports x87.
6. `challenge_accept`: the tables `DS:7D68`, `8BAE`, `8DD8` and the model columns `8DF2/8DF6/8DF8` are
   runtime data (from `HOT_DATA`); their exact file offsets belong to the garage spec. (Both
   comparisons are **unsigned**, `jae`/`jbe` at `0000:9c72/9cc9` — keep `uint16`.)
7. The gas-station and jail button logic (`b8a1`, `b08c`) and Bob's button ids are described from the
   decompile only (likely); the menu resources (`0f38:4a66` ids 0x12, 0x13, 0x16, 0x17, 0x18, 0x19,
   0x1A, 0x21, 0x25) are in the UI/video spec.
8. `DS:0286` (alternative sound path) disables the physics step entirely (`238c:2531`): if a sound
    option sets it during a race, the player's car would not move. Check who sets `DS:0286`.
